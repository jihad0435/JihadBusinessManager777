# Jihad Business Manager (Android project)

এটি একটি অফলাইন ব্যবসার সেল, পেমেন্ট ও বকেয়া হিসাব রাখার Android প্রজেক্টের প্রাথমিক সংস্করণ।

## কী আছে
- বাংলা / English ভাষা পরিবর্তন
- একই ইউজারনেমে একাধিক সেল যোগ
- প্রতিটি সেলের তারিখ, বিক্রয় ও প্রথম পেমেন্ট সংরক্ষণ
- পরবর্তীতে আলাদা পেমেন্ট এন্ট্রি
- স্বয়ংক্রিয় মোট বিক্রয়, মোট পেমেন্ট ও বকেয়া হিসাব
- গ্রাহক সার্চ, সেল এডিট/ডিলিট, গ্রাহক আর্কাইভ/ডিলিট
- JSON ব্যাকআপ এক্সপোর্ট/ইমপোর্ট
- ফোনে লোকাল ডেটাবেস; ইন্টারনেট বা অ্যাকাউন্ট লাগে না

## APK বানানোর উপায়
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio-তে `Open` চাপুন এবং এই ফোল্ডারটি নির্বাচন করুন।
3. Gradle sync শেষ হলে `Build > Build APK(s)` নির্বাচন করুন।
4. APK সাধারণত `app/build/outputs/apk/debug/app-debug.apk`-এ তৈরি হবে।
5. APK ফোনে কপি করে খুলুন; Android-এ প্রয়োজন হলে “Install unknown apps” অনুমতি দিন।

## গুরুত্বপূর্ণ
- এটি একটি starter project; APK এই ZIP-এর মধ্যে আগে থেকে তৈরি নেই।
- প্রথমে test data দিয়ে পরীক্ষা করুন এবং নিয়মিত JSON backup নিন।
- ফোন হারালে বা অ্যাপের ডেটা মুছে গেলে ব্যাকআপ ছাড়া লোকাল ডেটা ফেরত নাও পাওয়া যেতে পারে।
